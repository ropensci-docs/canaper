# Package index

## Community matrix randomization

- [`cpr_rand_comm()`](https://docs.ropensci.org/canaper/reference/cpr_rand_comm.md)
  : Randomize a single community matrix
- [`cpr_iter_sim()`](https://docs.ropensci.org/canaper/reference/cpr_iter_sim.md)
  : Simulate the number of iterations needed to generate a random
  community that is sufficiently different from the original community

## Randomization tests

The main focus of this package, conducting randomization tests of
biodiversity metrics

- [`cpr_rand_test()`](https://docs.ropensci.org/canaper/reference/cpr_rand_test.md)
  : Run a randomization analysis for one or more biodiversity metrics

## Classification

Functions to classify the results of the randomization test

- [`cpr_classify_endem()`](https://docs.ropensci.org/canaper/reference/cpr_classify_endem.md)
  : Classify phylogenetic endemism
- [`cpr_classify_signif()`](https://docs.ropensci.org/canaper/reference/cpr_classify_signif.md)
  : Classify statistical significance

Datasets included in this package
